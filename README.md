# plugmask

Plug config/mask key checks for twelve-factor services.

**Site:** https://theworker02.github.io/plugmask/

## Install / run

```bash
git clone https://github.com/theworker02/plugmask.git
cd plugmask
node src/cli.js
node --test
```
